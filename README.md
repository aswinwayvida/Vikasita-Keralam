# Vikasita Keralam Platform

Create a modern Malayalam-first civic and organisation management platform called “Vikasita Keralam”.

The platform has two parts:

1. Public website for citizens to discover Central Government schemes they are eligible for, submit application helpdesk requests, chat with an AI scheme assistant, view success stories, and register as volunteers.

2. Admin dashboard for BJP Kerala leadership and authorised workers to manage applications, volunteers, scheme helpdesk workflow, district/constituency/panchayat/ward-level performance, WhatsApp communication, and AI-powered reporting.

Design style:

- Clean, prestigious, professional political-public service platform

- Malayalam and English language toggle -

- Blue, saffron, white colour palette

- Mobile-first public website

- Serious admin dashboard with cards, filters, charts, tables, and role-based navigation

Public pages:

- Homepage

- Scheme Eligibility Finder

- Eligible Schemes Result Page

- Scheme Detail Page

- Application Helpdesk Form

- AI Scheme Assistant

- Volunteer Registration

- Contact Page

Admin pages:

- State Dashboard

- Application CRM

- Volunteer Management

- Scheme Analytics

- Panchayat/Constituency Growth Dashboard

- WhatsApp Campaign Centre

- AI Admin Copilot

- Settings and Role Management

Use sample Kerala data:

- Districts

- Assembly constituencies

- Panchayats

- Wards

- Central Government schemes

- Sample applications

- Sample volunteers

Create realistic UI with mock data. Make it look like a production-grade prototype suitable for presentation to senior political leadership.
